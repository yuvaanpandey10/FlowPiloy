# FlowPilot

FlowPilot is a fictional SaaS productivity platform website built with HTML, CSS, and vanilla JavaScript.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Git

## Features

- Responsive navigation
- SaaS landing page
- About page
- Services page
- Contact page
- Contact form UI
- Mobile navigation
- Responsive layout

## How to run

Open `index.html` in a browser.
